Technical Architecture & Security Framework

System Topology Security & DPDP Compliance

End-to-End System Architecture

Modular monolith API powering multi-tenant campus operations and high-stakes assessments

Three specialized frontends connect over secure TLS 1.3 to a high-throughput API gateway backed by PostgreSQL with hardware isolation.

1. Client Applications Tier (React 19 · Vite · Progressive Web Apps)
Staff & Admin Console Desktop-optimized web app for high-volume admissions, payroll, fee collections, timetabling and EMIS state reporting.
Teacher PWA Mobile-first PWA with an offline register outbox for daily attendance, marks entry, leave and homework without active Wi-Fi.
Parent & Student PWA Multi-child single login for live attendance feeds, fee receipts, digital report cards, and homework reminders.
CBT Exam Client Full-screen proctored environment supporting Safe Exam Browser (SEB), Face ID periodic capture, and offline answer buffering.
↓ ↑ HTTPS / WSS · Granular Permission Guards
2. API Gateway & Application Services Tier (Node 20 LTS · Express 5 · Zod)
Edge Security & Rate Limiting Strict CORS, Content Security Policy (CSP), DDoS protection, and IP-whitelisting for institutional testing labs.
Authentication & RBAC Guard JWT access + rotating refresh tokens; scrypt password hashing; TOTP MFA for administrative roles; OTP over SMS for parents.
Tenant Lifecycle Controller Enforces tenant states (active / read-only / suspended) at runtime. Automatically routes requests to tenant context.
35 Routers · 260 Endpoints Full lifecycle: SIS, admissions desk, fee ledger, question bank generator, real-time control board, and EMIS synchronizer.
↓ ↑ Connection Pooling · RLS Enforced Session Context
3. Data & Audit Tier (PostgreSQL 17 · Row-Level Security)
PostgreSQL 17 with RLS Every single table has a mandatory tenant_id. DB engine isolates tenant rows, preventing cross-tenant leakage.
Immutable Audit Log Append-only, hash-chained audit_events ledger. Every grade modification, fee transaction, and login is cryptographically verifiable.
DPDP Compliance Ledgers Consent ledgers, data-rights registers, and export logs ensuring full Indian DPDP Act 2023 statutory adherence.
Encrypted Backups Nightly automated encrypted snapshots, point-in-time recovery, and zero-downtime rolling database migrations.

Five Pillars of Institutional Reliability

How Scored guarantees speed, data safety, and exam integrity at scale

Engineered to eliminate single points of failure, human oversight in grading, and spreadsheet vulnerabilities.

Multi-Tenant Row-Level Security (RLS)

Rather than relying merely on software application filters that can fail during code bugs or SQL injections, Scored enforces tenant isolation directly in the PostgreSQL kernel.

  • App connects as non-bypass role (lumen_app)
  • Strict tenant boundary across all 46 database tables
  • Instant provisioning of new schools without code changes

High-Concurrency CBT & Anti-Cheat

Capable of supporting thousands of simultaneous exam-takers with sub-second answer persistence, dynamic question permutations, and automated tamper detection.

  • Safe Exam Browser (SEB) full-screen sandbox integration
  • Face ID periodic webcam snapshot & proctor review
  • Sub-second live exam control board for invigilators

DPDP Act 2023 & Cryptographic Audit

Built to exceed Indian Digital Personal Data Protection Act requirements through immutable event logging, consent management, and strict purpose limitation.

  • Append-only, SHA-256 hash-chained audit ledger
  • Granular guardian consent ledgers for minor data
  • Complete data export and right-to-forget pipelines

Offline-First PWA Synchronization

Poor school campus Wi-Fi or classroom connectivity never stops teachers from marking registers or recording grades. Local outbox queues flush automatically upon reconnection.

  • IndexedDB local persistence with zero loss guarantee
  • Conflict-free transactional sync upon network restore
  • Fast service-worker caching for instant cold launches

Granular RBAC (9 Roles · 56 Permissions)

Routes and UI controls are never checked against ambiguous role names. Every action requires explicit permission verification, protecting sensitive payroll and student records.

  • 56 granular permissions evaluated on every API request
  • Mandatory TOTP MFA for Admin, Principal, Accountant & Examiner
  • OTP-secured parental mobile access over encrypted SMS

Legacy Data Migration Pipeline

Switching from legacy spreadsheets or old desktop ERPs is completely automated. Our ingestion engine normalizes dirty data, cleans duplicates, and validates phone numbers.

  • Pre-flight dry runs before committing student records
  • Automatic detection of phone, email, and roll number conflicts
  • Historical fee ledger and attendance reconciliation
